# F5 – Uzdevumi un atgādinājumi

| Lauks | Vērtība |
| --- | --- |
| **ID** | F5 |
| **Prasības tips** | Funkcionālā |
| **Atkarības** | F0, F1, F3, F4, N3 |
| **Maršruti** | Lapa `/uzdevumi`, API `/tasks` |
| **Līgums** | `docs/openapi.yaml` · `GET/POST /tasks`, `GET/PUT /tasks/{id}`, `POST /tasks/{id}/complete` |
| **Statuss** | Īstenošanā. Lēmumus šajā aprakstā pieņēma izstrādātājs (MI aģents), un analītiķim tie jāapstiprina. |

## 1. Mērķis

Darbinieks pieraksta, kas viņam jāizdara un līdz kuram datumam, un var lūgt sistēmai atgādināt par to iepriekš. Uzdevumu var saistīt ar organizāciju, pieprasījumu vai mijiedarbības nākamo soli. Uzdevumi ir datu avots vadības panelim (F9: rādītājs "Uzdevumi šodien", bloks "Mani uzdevumi šodien", "Nākamie soļi").

## 2. Uzdevuma lauki

| Lauks | API nosaukums | Obligāts | Noteikumi |
| --- | --- | --- | --- |
| Nosaukums | `title` | Jā | 1–200 rakstzīmes pēc atstarpju noņemšanas |
| Termiņš | `dueDate` | Jā | `GGGG-MM-DD` |
| Atgādināt | `remindOn` | Nē | `GGGG-MM-DD`, ne vēlāk par termiņu |
| Izpildīts | `done` | Izveidojot nē (noklusējums `false`), labojot jā | `true` / `false` |
| Organizācija | `organizationId` | Nē | Organizācija, ko lietotājs redz (N3) |
| Pieprasījums | `requestId` | Nē | Pieprasījums, ko lietotājs redz |
| Mijiedarbība | `interactionId` | Nē | Mijiedarbība, ko lietotājs redz; izmanto, veidojot uzdevumu no nākamā soļa |

Saites norāda tikai izveidojot; pēc tam tās nemainās. Ja norādīts pieprasījums vai mijiedarbība, organizāciju sistēma nosaka pati. Ja norādīta arī `organizationId` un tā nesakrīt, atbilde ir 400 `organizationId` / `MISMATCH`.

Sistēma pati piešķir `id`, `ownerId` (pieslēgtais lietotājs), `completedAt`, `createdAt`, `updatedAt` un aprēķina pēc šodienas (Europe/Riga):

| Lauks | Aprēķins |
| --- | --- |
| `overdue`, `overdueDays` | Nav izpildīts un `dueDate` < šodien (F9 "Kavēts uzdevums") |
| `dueToday` | Nav izpildīts un `dueDate` = šodien |
| `reminderDue` | Nav izpildīts un `remindOn` ≤ šodien |
| `organizationName`, `requestTitle` | Saistītā ieraksta nosaukums vai `null` |

**Atgādinājums** ir uzdevums ar `reminderDue` = `true`. To rāda lapas augšā sadaļā "Atgādinājumi" (un vēlāk F9 panelī). E-pasta vai citi paziņojumi ārpus sistēmas netiek sūtīti (F9 ārpus apjoma).

## 3. Tiesības (N3)

| Darbība | Darbinieks | Vadītājs | Administrators |
| --- | --- | --- | --- |
| Izveidot | Sev | Sev | 403 |
| Skatīt | Savus | Savus; ar `team=true` visus | 403 |
| Labot, atzīmēt izpildītu | Savus | Savus; citu uzdevumus tikai skatīt (403) | 403 |

Uzdevumu nevar piešķirt citam lietotājam: īpašnieks vienmēr ir veidotājs. Darbiniekam sveši uzdevumi izskatās neesoši (404); `team=true` darbiniekam dod 403.

## 4. Darbības

- **Izveidot:** `POST /tasks` → 201.
- **Skatīt:** `GET /tasks/{id}`.
- **Labot:** `PUT /tasks/{id}` aizstāj `title`, `dueDate`, `remindOn`, `done`. Atzīmējot `done` = `true`, tiek iestatīts `completedAt`; atverot no jauna – notīrīts.
- **Atzīmēt kā izpildītu:** `POST /tasks/{id}/complete` → 200 (bez ķermeņa; vajadzīgs F9 pogai "Atzīmēt kā izpildītu"). Atkārtots izsaukums `completedAt` nemaina.
- **Saraksts:** `GET /tasks`, sakārtots pēc termiņa, tad ID. Filtri apvienojas ar "un":

| Parametrs | Nozīme | F9 lietojums |
| --- | --- | --- |
| `team` | `true` – visu lietotāju uzdevumi (tikai vadītājam) | Komandas skats |
| `done` | `true` / `false` | "Mani uzdevumi šodien" (`false`) |
| `dueWithinDays` | Termiņš ≤ šodien + N, ieskaitot kavētos; 0–365 | `0` – šodienas un kavētie |
| `remindersDue` | `true` – tikai uzdevumi, par kuriem šodien jāatgādina | Atgādinājumi |
| `organizationId` | Tikai šīs organizācijas uzdevumi | Organizācijas kartīte |
| `interactionId` | Tikai no šīs mijiedarbības izveidotie | "Nākamie soļi" bez uzdevuma |

## 5. Lapa `/uzdevumi`

- Nepieslēgts → `/login`; administrators → `/admin` (N3). Navigācijā saite "Uzdevumi".
- Sadaļa "Atgādinājumi" ar uzdevumiem, kuriem `reminderDue` = `true`; ja tādu nav, tā netiek rādīta.
- Filtri: "Rādīt izpildītos", vadītājam "Komandas uzdevumi".
- Tabula ar `<caption>` un `<th scope="col">`: Uzdevums, Saistīts ar, Termiņš, Statuss, Darbības. Kavētie apzīmēti ar tekstu "Kavēts, N d.", šodienas – "Šodien" (ne tikai krāsa).
- Poga "Atzīmēt kā izpildītu"; pēc tās lietotājs paliek lapā un ekrāna lasītājs nolasa "Uzdevums atzīmēts kā izpildīts" (`role="status"`).
- Forma izveidei un labošanai: nosaukums, termiņš, atgādināt, organizācija (izvēle no redzamajām). Adreses parametri `title`, `organizationId`, `requestId`, `interactionId` aizpilda formu (F9 "Izveidot uzdevumu" no nākamā soļa).
- Tukšā stāvokļa teksts: "Nav uzdevumu."
- Organizācijas kartītē pie mijiedarbības ar nākamo soli – saite "Izveidot uzdevumu".

## 6. Pieņemšanas kritēriji

| ID | Ievade / situācija | Sagaidāmais rezultāts |
| --- | --- | --- |
| F5-1 | `POST` ar nosaukumu un termiņu | 201; `ownerId` = pieslēgtais lietotājs, `done` = `false`, saites `null` |
| F5-2 | `POST` bez `title` vai `dueDate` | 400 `VALIDATION_ERROR`, `REQUIRED` |
| F5-3 | Nederīgs datums; `remindOn` pēc `dueDate` | 400, `INVALID_FORMAT`; `remindOn` / `AFTER_DUE_DATE` |
| F5-4 | `POST` ar `requestId` vai `interactionId` | `organizationId` un nosaukumi aizpildīti no saistītā ieraksta |
| F5-5 | `organizationId` nesakrīt ar pieprasījuma organizāciju | 400, `organizationId` / `MISMATCH` |
| F5-6 | Saite uz neesošu vai svešu organizāciju, pieprasījumu, mijiedarbību | 400, attiecīgais lauks / `NOT_FOUND` |
| F5-7 | Termiņš vakar, nav izpildīts; termiņš šodien | `overdue` = `true`, `overdueDays` = 1; `dueToday` = `true` |
| F5-8 | `remindOn` = šodien vai agrāk, nav izpildīts | `reminderDue` = `true`; pēc izpildes `false` |
| F5-9 | `POST /tasks/{id}/complete` | 200; `done` = `true`, `completedAt` aizpildīts; nav vairs `done=false` sarakstā |
| F5-10 | `PUT` ar `done` = `false` izpildītam uzdevumam | `completedAt` = `null` |
| F5-11 | `GET /tasks?done=false&dueWithinDays=0` | Tikai neizpildītie šodienas un kavētie, kavētie augšā |
| F5-12 | Darbinieks pieprasa sveša lietotāja uzdevumu; `team=true` | 404; 403 |
| F5-13 | Vadītājs ar `team=true`; vadītājs labo svešu uzdevumu | Redz visus; 403 |
| F5-14 | Administrators; nav sesijas | 403; 401 |
| F5-15 | Lapa `/uzdevumi` | Nepieslēgts → `/login`; administrators → `/admin`; darbiniekam 200 ar tabulu un formu |

## 7. Ārpus apjoma

- Uzdevumu piešķiršana citam lietotājam.
- Atkārtoti uzdevumi, prioritātes, apakšuzdevumi.
- Paziņojumi e-pastā vai pārlūkā.
- Dzēšana, lapošana.
