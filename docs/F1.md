# F1 – Organizācijas: izveidot, rediģēt, meklēt

| Lauks | Vērtība |
| --- | --- |
| **ID** | F1 |
| **Prasības tips** | Funkcionālā |
| **Atkarības** | F0 (Login un reģistrācija) |
| **Maršruti** | Lapa `/organizacijas`, API `/organizations` |
| **Līgums** | `docs/openapi.yaml` · `GET/POST /organizations`, `GET/PUT /organizations/{id}` |
| **Statuss** | Īstenošanā. Lēmumus šajā aprakstā pieņēma izstrādātājs (MI aģents), un analītiķim tie jāapstiprina. |

## 1. Mērķis

Darbinieks uztur organizāciju sarakstu, ar kurām iestāde sadarbojas. Organizācija ir pamatieraksts, uz kuru atsaucas kontaktpersonas (F2), mijiedarbības (F3), pieprasījumi (F4), uzdevumi (F5) un vadības panelis (F9).

## 2. Organizācijas lauki

| Lauks | API nosaukums | Obligāts | Noteikumi |
| --- | --- | --- | --- |
| Nosaukums | `name` | Jā | 1–200 rakstzīmes pēc atstarpju noņemšanas sākumā un beigās |
| Reģistrācijas numurs | `regNumber` | Nē | Tieši 11 cipari; unikāls starp organizācijām |
| Adrese | `address` | Nē | Līdz 300 rakstzīmēm |
| Atbildīgais darbinieks | `responsibleUserId` | Nē | Esoša lietotāja ID. Ja nav norādīts izveidojot, atbildīgais ir pats veidotājs |

Sistēma pati piešķir `id`, `createdAt` un `updatedAt`. Tukša virkne neobligātajā laukā tiek saglabāta kā `null`.

Organizācijas laukos nav personas datu. Kontaktpersonas ir F2 tvērumā.

## 3. Darbības

- **Izveidot:** `POST /organizations` → 201 un izveidotā organizācija.
- **Skatīt:** `GET /organizations/{id}` → 200 vai 404.
- **Rediģēt:** `PUT /organizations/{id}` aizstāj visus rediģējamos laukus → 200. `responsibleUserId`, ja tas nav norādīts, paliek nemainīts.
- **Meklēt:** `GET /organizations?q=&mine=`
  - `q` meklē daļēju sakritību nosaukumā un reģistrācijas numurā. Lielie un mazie burti netiek šķirti (`Ā` = `ā`), bet garumzīmes tiek ņemtas vērā (`ā` ≠ `a`).
  - `mine=true` atstāj tikai organizācijas, kurām pieslēgtais lietotājs ir atbildīgais (vajadzīgs F9 rādītājam "Manas organizācijas").
  - Rezultāts sakārtots pēc nosaukuma latviešu alfabēta secībā (`Ābele` pirms `Bērzi`).

Visām darbībām vajag pieslēgšanos (sesijas sīkdatne no F0); bez tās atbilde ir 401 `UNAUTHORIZED`.

## 4. Lapa `/organizacijas`

- Nepieslēgts lietotājs tiek novirzīts uz `/login`.
- Meklēšanas forma (lauks "Meklēt pēc nosaukuma vai reģ. nr." un izvēles rūtiņa "Tikai manas").
- Rezultātu tabula ar `<caption>` un `<th scope="col">`: Nosaukums, Reģ. nr., Adrese, darbība "Rediģēt".
- Viena forma izveidošanai un rediģēšanai; kļūdas parādās pie attiecīgā lauka; paziņojumi tiek nolasīti ekrāna lasītājā (`role="status"`).
- Tukšā stāvokļa teksts: "Nav atrasta neviena organizācija."

## 5. Pieņemšanas kritēriji

| ID | Ievade / situācija | Sagaidāmais rezultāts |
| --- | --- | --- |
| F1-1 | `POST` ar derīgu `name` | 201; atbildē `id`, `name`, `responsibleUserId` = pieslēgtais lietotājs |
| F1-2 | `POST` bez `name` vai ar tikai atstarpēm | 400 `VALIDATION_ERROR`, `name` / `REQUIRED` |
| F1-3 | `name` garāks par 200 rakstzīmēm | 400, `name` / `TOO_LONG` |
| F1-4 | `regNumber` = `"123"` | 400, `regNumber` / `INVALID_FORMAT` |
| F1-5 | `regNumber`, kas jau ir citai organizācijai | 409 `ALREADY_EXISTS`, `regNumber` / `ALREADY_EXISTS` |
| F1-6 | `responsibleUserId`, kāda lietotāja nav | 400, `responsibleUserId` / `NOT_FOUND` |
| F1-7 | `PUT` ar derīgiem datiem | 200; dati mainīti, `updatedAt` atjaunots |
| F1-8 | `GET` vai `PUT` neesošai organizācijai | 404 `NOT_FOUND` |
| F1-9 | `GET /organizations?q=rīga` | Atrod "SIA Rīgas Ūdens" un "RĪGAS DOME"; neatrod "Ogres pils" |
| F1-10 | `GET /organizations?q=4000` | Atrod organizāciju ar reģ. nr., kurā ir "4000" |
| F1-11 | `GET /organizations?mine=true` | Tikai organizācijas, kurām atbildīgais ir pieslēgtais lietotājs |
| F1-12 | Jebkurš pieprasījums bez sesijas | 401 `UNAUTHORIZED`; dati netiek mainīti |
| F1-13 | Lapa `/organizacijas` bez sesijas | Novirzīšana uz `/login` |
| F1-14 | Lapa `/organizacijas` ar sesiju | 200; lapā ir meklēšanas forma, tabula ar `<caption>` un organizācijas forma |

## 6. Ārpus apjoma

- Lomas un redzamības ierobežojumi – sk. [N3.md](N3.md): darbinieks redz un labo tikai savas organizācijas, vadītājs visas un tikai viņš maina atbildīgo.
- Organizāciju dzēšana un arhivēšana.
- Lapošana (pagination).
- Reģistrācijas numura pārbaude Uzņēmumu reģistrā.
- Izmaiņu vēsture un piekļuves žurnāls (N2).
